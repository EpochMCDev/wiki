# 经济系统

本服务器拥有独特的**市场经济**：矿物的价格会随着市场的需求而浮动。除此之外，你还可以通过**签到、在线奖励**等途径获取金币。

> 服务器货币统一为**金币**，签到、在线奖励、城镇 / 国家运营均使用同一货币。

## 矿物商人

菜单内已不再内置矿物市场，出售矿物请前往 **联合商业区** 的**矿物商人**：

![巴尔加德矿物商人](/img/矿物商人.png)

- 矿物价格随市场供需动态浮动，出售时价格会实时变化。
- 多关注市场价格，在需求较高、价格理想时出手，能获得更高收益。

## 获取金币的途径

| 途径 | 说明 |
| --- | --- |
| 矿物商人 | 前往联合商业区出售矿物，价格随市场浮动 |
| 签到奖励 | 每日签到获得 250 金币 + 20 级经验，另随机获得钻石 0-1、铁锭 4-12；详见下方签到奖励表 |
| 在线奖励 | 通过主菜单「在线奖励」（/pms open time）领取 |
| 交易 | 箱子商店出售物品 |

### 签到奖励明细（/signin gui）

| 条件 | 奖励 |

| 每日签到 | 钻石 0-1 + 铁锭 4-12 + 250 金币 + 20 级经验 |
| 连续签到 3 天 | 钻石×1 + 金锭×3 + 铁锭×6 |

| 每连续 3 天（周期） | 金苹果×1 |
| 周日签到 | 金苹果×1 |
| 累计签到 100 次 | 10000 金币 |
| 每累计 100 次（周期） | 500 金币 |
| 全服首个签到 | 钻石×2 + 金锭×5 + 铁锭×12 |

| 12-25 圣诞 / 01-01 元旦 | 苹果×32 / 苹果×64 |

## 国家股市

国家股市是**快速来钱的方式之一**，事关国家经济命脉。

- 股市网址：[epochearth.cn:54754](http://epochearth.cn:54754/)
- 菜单主页也可以选择游戏内的 GUI 进入股市

> 注意：国家股市目前有 bug，使用中可能出现异常。

## 金币的消耗途径

| 途径 | 说明 |
| --- | --- |
| 建立城镇 | 创建城镇需 **5 万金币**，之后每天缴纳 **1000 金币**维护费 |
| 建立国家 | 创建国家需 **20 万金币**（须先成为城主），之后每天缴纳 **5000 金币**维护费 |
| 城镇资源升级 | 1~4 级城镇资源分别需 **2.5 万 / 10 万 / 50 万 / 120 万金币** |
| 圈地 | 圈占领地、购买领地需要消耗金币 |
| 购买物品 | 在商店购买物品、道具 |
| 传送费用 | 城镇 / 国家传送等产生的费用 |
| 城镇税收 | 居民需按城镇设定缴纳居民税等税费 |
