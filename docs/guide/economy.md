# 经济系统

本服务器拥有独特的**市场经济**：矿物的价格会随着市场的需求而浮动。除此之外，你还可以通过**签到、在线奖励**等途径获取金币。

## 矿物商人

菜单内已不再内置矿物市场，出售矿物请前往 **联合商业区** 的**矿物商人**：

![巴尔加德矿物商人](/img/矿物商人.png)

- 矿物价格随市场供需动态浮动，出售时价格会实时变化。
- 多关注市场价格，在需求较高、价格理想时出手，能获得更高收益。

## 获取金币的途径

| 途径 | 说明 |
| --- | --- |
| 矿物商人 | 前往联合商业区出售矿物，价格随市场浮动 |
| 签到奖励 | 每日签到获取金币 |
| 在线奖励 | 累计在线时长领取金币奖励 |

## 国家股市

国家股市是**快速来钱的方式之一**，事关国家经济命脉。

- 股市网址：[epochearth.cn:54754](http://epochearth.cn:54754/)
- 菜单主页也可以选择游戏内的 GUI 进入股市

> 注意：国家股市目前有 bug，使用中可能出现异常。

## 金币的消耗途径

| 途径 | 说明 |
| --- | --- |
| 建立城镇 / 国家 | 创建城镇、组建国家需要消耗启动资金 |
| 圈地 | 圈占领地、购买领地需要消耗金币 |
| 购买物品 | 在商店购买物品、道具 |
| 传送费用 | 城镇 / 国家传送等产生的费用 |
| 城镇维护费 | 城镇每天需缴纳维护费用，资金不足会破产 |
| 国家维护费 | 国家同样需要缴纳维护费用 |
| 城镇税收 | 居民需按城镇设定缴纳居民税等税费 |

## 常用指令
