# 附魔与强化

## 附魔

- 野外遗迹**不会刷新附魔书**。
- **附魔台只能通过开物资箱获得**。
- 附魔书可以通过**合成**获得（以下为部分合成链）。

### 附魔书合成链

| 附魔书 | 合成方式（节选） |
| --- | --- |
| 效率 I → V | 紫水晶碎片 + 绿宝石 + 附魔书 → … → 铱 + 下界之星 |
| 保护 I → IV | 紫水晶碎片 + 铬合金 + 附魔书 → … → 黑金刚锭 |
| 锋利 I → V | 紫水晶碎片 + 钛合金 + 附魔书 → … → 锂锭 + 精金 |
| 耐久 I → III | 紫水晶碎片 + 镍锭 + 附魔书 → … |
| 击退 I / II | 绿宝石（压缩绿宝石）+ 末影水晶 |
| 精准采集 I | 石英 + 下界之星 |
| 爆炸保护 I / II | 紫水晶碎片 + 钢筋板 |
| 荆棘 I / II | 紫水晶碎片 + 多功能工具 |

> 任意附魔书也可在**锻造台**用「紫水晶碎片 + 压缩青金原石 + 书」合成。

### 强化紫水晶

配方不在 JEI 显示：**紫水晶**在上、**压缩青金原石**在下放入酿造台酿造，可得到强化紫水晶（附魔书合成的重要材料）。

## 装备强化

使用 **炉岩碳 / 高级炉岩碳** 在熔炉中烧制，可以为装备强化：

- 强化等级最高为 **20 级**。
- **10 级以下**强化失败会**掉级**；**10 级及以上**失败装备**消失**。
- 使用**强化药水**可以提高强化成功率。
- **高级炉岩碳**的强化成功率为炉岩碳的 **140%**。

## 合金套与要塞

- **锻造台不允许直接获取**，需要前往**要塞**锻造合金套。
- 要塞可被任意城镇占领（欧洲 6 座、亚洲 5 座，详见战争系统）。
