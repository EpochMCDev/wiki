# 箱子商店

服务器使用 **QuickShop-Hikari** 插件，在箱子旁放置告示牌即可创建玩家商店。

- **创建商店**：手持想要出售的物品，**左键点击一个箱子**即可创建商店。
- 修改价格：`/qs price [价格]`（或右键告示牌调整）。
- 删除商店：`/qs remove`。
- 查看商店信息：`/qs info`。
- 切换收购 / 出售模式：`/qs buy`、`/qs sell`。
- **需要先登录账号**（未登录玩家无法使用商店）。

> 商店交易使用服务器统一的**金币**货币。

## 购买商品

需要购买物品时，可以前往**联合商业区**（主菜单「前往联合国商业区」可传送），那里的玩家商店出售各类物品与材料。
