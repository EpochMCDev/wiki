# 交易与市场

## 箱子商店（QuickShop-Hikari）

服务器使用 **QuickShop-Hikari** 插件，在箱子旁放置告示牌即可创建玩家商店。

- **创建商店**：手持想要出售的物品，**左键点击一个箱子**即可创建商店。
- 修改价格：`/qs price [价格]`（或右键告示牌调整）。
- 删除商店：`/qs remove`。
- 查看商店信息：`/qs info`。
- 切换收购 / 出售模式：`/qs buy`、`/qs sell`。
- **需要先登录账号**（未登录玩家无法使用商店）。

> 商店交易使用服务器统一的**金币**货币，具体税收以服务器实际设置为准。

## 全球市场（GlobalMarketPlus）

- 使用 `/gmp` 相关命令或菜单打开全球市场。
- **上架即收税**：出售 / 拍卖商品上架时先收税。
  - 默认组税率 **5%**（部分权限组可享更低税率）。
- 支持出售、收购、拍卖、邮箱等玩法。

## 便捷商店

- 通过主菜单「便捷商店」（/shopgui）购买常用物品与材料。

> 交易都使用服务器统一的**金币**货币。
