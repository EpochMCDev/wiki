# 科技系统（Slimefun）

服务器使用 **Slimefun（粘液科技）** 提供工业与科技玩法，包括各类机器、合金与自动化产线。

## 快速开始

- 输入 `/sf guide`（或 `/sf open_guide`）可获取一本 Slimefun 教程书 / 直接打开教程书。
- 服务器自定义的合金、装备等合成配方推荐安装 **JEI** 查看，详见[《自定义物品》](/docs/guide/custom-items)。

## 详细教程

Slimefun 的机器、物品与玩法非常丰富，完整的图鉴与教程请移步：

**👉 [粘液科技中文 Wiki](https://slimefun-wiki.guizhanss.cn/)**

> 服务器科技玩法以游戏内 `/sf open_guide` 为准，粘液科技 Wiki 提供通用机制讲解。
