# 港口系统

港口体系是连接世界各地的快速交通方式。你可以在各个港口间**购买船票**快速穿行，是跨越大洋的主要途径。

## 使用方法

1. 前往任意港口。
2. 在港口**右键控制台（制图台）**，即可选择可通行的港口。
3. 购买船票后快速穿行到目标港口。

## 注意事项

- **欧洲和亚洲必须通过港口才能够穿行**。
- **请勿重复选择你所在的港口！**
