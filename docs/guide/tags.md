# 称号系统

使用 `/tags` 打开称号界面，选择你拥有的称号。称号大多通过**权限 / 成就**获得：

| 称号 | 获取方式 |
| --- | --- |
| [腐竹] | 服务器所有者 |
| [管理员] | 服务器管理 |
| [萌新] / [玩家] / [流浪者] / [危险人物] | 基础称号 |
| [传奇老玩家] | 单日在线时长达 14 小时 |
| [bilibili] | 在 bilibili 宣传服务器 |
| [Helper] | 为服务器做出突出贡献 |
| [斯特吉亚之冠] | 斯特吉亚活动冠军 |
| [最佳承办] | 斯特吉亚活动最佳承办 |
| 国家国主称号 | 担任国家国主 |
