# 烹饪与种植

## 烹饪系统

### 厨房设施

| 设施 | 对应方块 | 说明 |
| --- | --- | --- |
| 切菜板 | 原木 | 切分食材 |
| 烧烤架 | 脚手架 | 烧烤食材 |
| 炖锅 | 炼药锅 | 熬汤（需成就「深夜厨房」解锁） |

- **菜刀**：木菜刀（40 耐久）；精钢菜刀（120 耐久，需成就解锁）。
- 烹饪有「半熟 / 完美 / 烤过头 / 烧焦」判定，不同时间对应不同品质。
- 完美品质的食物带强力效果；切好 / 烤好的食材放久了会**变质**（40-60 秒）。

### 经验与等级

- 每级需要 **20 经验**，最高 **10 级**。
- 每升 1 级：**+4% 烹饪速度**、**+0.3 完美判定窗口**（更容易烤出完美品质）。

## 种植系统

基于 **ExoticGarden（异域花园）** 与 Gastronomicon：

- **48 种作物种子**可通过打草掉落获得：番茄、葡萄、茶、咖喱叶、姜、洋葱、花生、玉米、红薯、蓝莓、草莓、西瓜、南瓜、各类果树树苗等。
- **下界 / 末地**不掉落种子。
- 树木类种子掉落率约 22%，灌木类约 16%。
- 可使用骨粉式摇晃加速生长；浇水壶有几率催熟。
- Gastronomicon 联动：鱿鱼 / 守卫者 / 山羊 / 鲑鱼有 35% 概率掉落特殊食材；草 5%、海草 15% 掉落种子。

> 美食家（Gastronomicon）还有厨师熟练度系统：熟练度 0=不是厨师、1=新手、50=学徒、100=经验丰富、200=三星大厨。
