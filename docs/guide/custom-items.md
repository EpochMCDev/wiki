# 自定义物品

服务器提供了丰富的自定义物品与合成：合金生产线、专属装备、特殊箭矢与火器等。自定义配方推荐安装 **JEI** 查看。

## 合金生产线

矿物 → 合金是科技线的核心。基础流程：

1. **开采铬矿 / 钛矿**（主世界深层/石层生成），高炉熔炼成**铬锭 / 钛锭**等。
2. 用**合金碳**（煤炭块 + 下界合金锭）+ 对应金属锭合成**铝合金、铬合金、镁合金、镍合金、钛合金、锡合金**等。
3. 继续合成**强化钛合金、金钛合金、强化钛金合金、镁铝合金、钛钢合金、黑金刚锭**等高级材料。

常用产物：碳纤维板、树脂、电路板、铜线、强化紫水晶、精炼钻石块、压缩绿宝石、下界之星碎片、命座等。
