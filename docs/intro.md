## 关于我们

Epoch MC 成立于 2026 年 7月，是一款以 **1:50 真实地球**为地图的国战服务器，聚焦**领土、战争、外交与经济博弈**，为玩家提供沉浸式的国家模拟体验。

- 真实地球地图：1:50 比例真实地形，你的疆域由你丈量
- 建国与圈地：从第一片领土开始，建立属于你的国家
- 战争与外交：宣战、结盟、停战，重塑世界格局
- 城市建造：打造首都、城市群与基础设施
- 国家股市：用经济博弈左右国际局势
- 社群协作：与志同道合的伙伴共创纪元
- 粘液科技：工业机械与自动化生产

**技术规格**：

- ▸ 当前游戏版本：Minecraft Java 1.20.1
- ▸ 服务端核心：EpochCore
- ▸ 地图比例：1:50 真实地球
- ▸ 核心玩法：国战 / 生存
- ▸ 科技插件：粘液科技（Slimefun）
