# 新人须知

欢迎来到 **Epoch MC**。这是一份为第一次进入服务器的你准备的新手指南，建议先通读再进服。

## 服务器简介

- 以 **1:50 真实地球**为地图的国战服务器，聚焦领土、战争、外交与经济博弈。
- 当前游戏版本：Minecraft **Java 1.20.1**。
- 核心玩法：国战 / 生存；科技插件：粘液科技（Slimefun）。
- 服务端核心：EpochCore。

## 快速加入

无需提交入服申请，三步即可进入：

1. **加入 QQ 群**：官方 QQ 群 `1043737743`（[点击加入](https://qm.qq.com/q/M2NJEm15uc)），支持离线登录。
2. **获取整合包**：在 QQ 群文件中下载官方整合包，按说明完成安装。
3. **进入游戏**：启动整合包，连接服务器地址开始游戏。

<div className="notice-important">

**重要提醒**：请务必通过官方 QQ 群获取整合包与最新信息，谨防非官方渠道。

**进服注册**：首次进入服务器，请先输入 `/register <密码> <确认密码>` 注册账号；后续每次进服输入 `/login <密码>` 登录。

**新手福利**：进入服务器会给予玩家一套铁质护甲、一套石质工具，外加一张床和少量食物，帮助你在前期顺利起步。

</div>

## 主城与传送 NPC

进入服务器后会先来到**主城**。主城前方有两个 NPC：**左边**是传送到**亚洲地区**的 NPC，**右边**是传送到**欧洲地区**的 NPC。

## 港口穿行

欧洲和亚洲之间需要借助**港口**穿行——在港口右键控制台（制图台）购买船票即可。

详见[《港口系统》](/docs/guide/ports)。

## 死亡与重生

- 死亡之后会自动出生在**欧洲出生点**。
- 记得使用**床**保存重生点，避免死后回到出生点。
- 在菜单中可以返回自己保存的床。
- 在欧洲出生点点击**金块**，可以快捷传送到**马赛港**。

## 新手须知要点

- **加入限制**：注册时间未满 3 小时的玩家**不能加入任何城镇与国家**，满 3 小时后请慎重考虑。
- **遵守规则**：进服前请务必阅读[《服务器规则》](/docs/rules/overview)，违规会被警告、禁言甚至封禁。
- **谨慎开销**：圈地、建城镇 / 国家都需要消耗金币，建成后还需持续缴纳维护费。
- **防骗提示**：请勿轻信非官方渠道的"公告"和交易，谨防被骗。

## 如何赚钱

- **出售矿物**：前往**联合商业区**的**矿物商人**出售，价格随市场需求浮动。
- **签到奖励**：每日签到获取金币。
- **在线奖励**：累计在线时长领取金币。

## 金币的用途

- 建立城镇 / 国家、圈地、购买物品。
- 传送费用、城镇 / 国家维护费、城镇税收。

详见[《经济系统》](/docs/guide/economy)。
