# 常见问题 FAQ

**Q：需要正版 Minecraft 才能加入吗？**
A：不需要，服务器支持离线登录（AuthMe 密码注册）。没有正版账号也可以正常游玩。

**Q：如何注册 / 登录？**
A：首次进服输入 `/register <密码> <确认密码>` 注册；后续每次进服输入 `/login <密码>` 登录。密码长度 5-30 位，同一 IP 最多注册 2 个账号。

**Q：登录不上去 / 密码忘了怎么办？**
A：输错密码会被踢出；密码遗忘可找管理组协助（涉及账号找回）。

**Q：什么是国战服？**
A：以 1:50 真实地球为地图，玩家可以建国圈地、宣战结盟、发展经济，通过战争与外交重塑世界格局。

**Q：整合包在哪里获取？**
A：加入 QQ 群（1043737743）后，在群文件中下载官方整合包，解压后启动即可。材质包由服务器自动下发，进服请保持「服务器资源包可用」。

**Q：服务器有哪些规则？**
A：详见[《服务器规则》](/docs/rules/overview)。重点：禁止科技（飞行/杀戮/矿透）、禁止利用 Bug、禁止毁坏环境建筑、禁止大型生电机器（占地小于 4 区块的机器可以造，全自动机器与刷物机禁止）、战时爆兵即 ban、公屏脏字/阴阳禁言。

**Q：死亡会怎样？**
A：死亡后自动出生在欧洲出生点（记得用床保存重生点），损失当前等级 **10% 经验**并获得短暂虚弱。可以用「命座」（每座 +2 心，最高 16 心/32 血）提升生命上限，「保护符」可免除一次死亡惩罚。

**Q：附魔台和附魔书怎么获得？**
A：附魔台只能通过**物资箱**开出；附魔书可以**合成**（详见[《附魔与强化》](/docs/guide/enhance)）。

**Q：锻造台不能放/不能合成？**
A：本服禁用锻造台合成，需要前往**要塞**锻造合金套。

**Q：为什么有些物品不能用？**
A：本服禁止：酿造药水（炼药锅酿造）、放置附魔台/末影箱/末地传送门框架/凋灵骷髅头、合成锻造台。地狱与末地已禁用。

**Q：怎么快速赚钱？**
A：去联合商业区的**矿物商人**卖矿物（价格随市场浮动）、每日签到、参加钓鱼比赛、箱子商店交易。详见[《经济系统》](/docs/guide/economy)。

**Q：怎么快速往返欧洲和亚洲？**
A：通过**港口**购买船票穿行（欧亚之间必须走港口）。详见[《港口系统》](/docs/guide/ports)。

**Q：有宠物/家/传送吗？**
A：有。/home 设置家（默认 3 个），菜单「返回存档点」可回床点。

**Q：红石机器可以造吗？**
A：禁止红石自动化，但**占地小于 4 区块的机器可以建造**；全自动机器、刷物机（铁轨机、线机等）禁止。
