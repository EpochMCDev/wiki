# 服务器规则

以下为 Epoch:Earth 服务器菜单内发布的官方规则，最终解释权归管理组所有。

## 禁止作弊与利用 Bug

- 请勿使用科技（飞行、杀戮、矿透等）。
- 请勿利用任何服务器 Bug。

## 建筑与地形

<div className="notice-warning">

**禁止红石**：服务器内禁止使用红石，**占地小于 4 区块**的机器可以建造。

- **全自动机器**禁止。
- **刷物机**（如铁轨机、线机）禁止。

</div>

- 严禁建造岩浆墙、黑曜石墙、石头金字塔等毁坏服务器环境的建筑。
- 严禁大规模毁坏服务器地形。
- 严禁建造大型生电机器。
- 建造小型生电机器需获管理组批准。

## 城镇与国战

- 严禁将前哨 / 城镇建立在敌对 / 中立城镇附近。
- 战时 / 战前爆兵：即刻 Ban。
- 战时 / 战前城镇大规模退国家：警告后 Ban。
- 战时 / 战前玩家大规模退城镇：警告后 Ban。

> 以上二者（退国家、退城镇）自 8/6 开始实行。

## 聊天规范

- 公屏聊天带有脏字：禁言。
- 公屏聊天语气阴阳：禁言。
